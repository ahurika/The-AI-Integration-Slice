# UI & UX Rules

**Priority:** HIGH

Authentication interfaces must provide clear:

* Initial states
* Loading states
* Success states
* Validation errors
* Authentication errors
* Server errors
* Disabled states

## Forms

Forms must have:

* Accessible labels
* Appropriate input types
* Clear validation
* Useful error messages
* Keyboard accessibility

## Accessibility

Consider:

* Keyboard navigation
* Focus management
* Screen readers
* Semantic HTML
* Error announcements

## Responsive Behaviour

Authentication interfaces must work across:

* Mobile
* Tablet
* Desktop

## UX Principle

The user should always understand:

```text
What happened?
Why did it happen?
What should I do next?
```
