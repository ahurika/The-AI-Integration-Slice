# Frontend Authentication Skill

## Purpose

Build accessible and responsive authentication interfaces.

## Workflow

For each screen:

1. Identify user goal.
2. Identify required fields.
3. Define validation.
4. Define loading state.
5. Define success state.
6. Define error states.
7. Implement responsive layout.
8. Verify accessibility.

## Components

Prefer reusable components for:

* Inputs
* Buttons
* Form fields
* Error messages
* Loading states
* Password inputs

## Client Components

Use Client Components only when required.

Do not make entire pages client-side unnecessarily.

## Accessibility

Verify:

* Labels
* Focus
* Keyboard navigation
* Semantic structure
* Error communication

## UX Principle

Make the user's next action obvious.
