# Project Foundation Rules

**Priority:** HIGH

## Purpose

Establish the foundational rules for the Authentication Slice.

## Rules

1. The approved repository structure must be preserved.
2. `PRD.md` defines product requirements.
3. `ARCHITECTURE.md` defines technical architecture.
4. `AGENTS.md` defines agent behaviour.
5. `.agents/rules/` defines implementation constraints.
6. `.agents/skills/` defines repeatable implementation procedures.
7. Do not invent requirements.
8. Do not change the approved stack without authorization.
9. Do not introduce unnecessary dependencies.
10. Do not restructure the repository casually.

## Pre-Coding Requirement

The project foundation must exist before feature implementation.

## Principle

Build from documented decisions rather than creating architecture accidentally during implementation.
